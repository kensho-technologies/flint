# Contributing

This repository is the reference implementation for [From Benchmarks to Production: A Text-to-SQL System for Complex Financial Data](https://arxiv.org/abs/2610.03524) 
presented at EMNLP Industry Track 2026. It is published so the
results in the paper can be reproduced, and it reflects the code as it was at
the time of publication.

The repository is archived and not actively maintained. We are not accepting
pull requests, feature requests, or issues. You are welcome to fork it under
the terms of the LICENSE file.

For questions about the paper or the method, please contact the authors at the
addresses listed in the paper.
